# 字体与口播排版

字体是固定口播风格的一部分。先核对原片同类镜头的字形、层级和排版，再选可用且授权合适的字体；增加动效不能弥补文字体系不对。已有配方中的替代字体只表示可编辑的近似方案，不证明原片使用了该字体。用户确认的字幕偏好优先于旧配方；展示字的风格不能覆盖口播字幕。

## 底部口播字幕的默认样式

遵守 [单处底部字幕规则](editorial-playbook.md#口播字幕只保留底部一处)，独立设置字幕角色。默认使用 Noto Sans SC 等已验证的常规黑体、真实400字重、字距0、宽高比1；字号按画幅和实际观看比例保证清楚，不靠加粗提升可读性。优先白字配轻描边或柔和阴影，在亮背景上必要时增加克制的底衬。描边不是第二份字形，避免粗描边和多层重影造成笔画重新变粗。

使用目标字体的实际400轮廓；单字重展示字体的文件即便标400，其原生笔画也可能很粗，不因此作为常规字幕黑体。字幕不继承标题的窄化、倾斜、手写或装饰阴影。只有用户明确要求时才改为其他字幕体系，并记录覆盖配置。

内置默认模板与暖黑模板的 `.caption-inner` 独立使用 `THCaptionSans`。`motion.py build` 仅在存在字幕cue时，按下方清单校验／下载Noto Sans SC及OFL许可，缓存到项目 `assets/fonts/caption`，复制到 `public/assets/fonts/caption` 并保存字体SHA清单；不向系统安装。已有精确缓存直接复用，字节不符则停止。组件测量前实际加载400字重，不继承仅800的展示字体。无cue项目不下载或注册字幕字体。

## 对照什么

比较人物主讲字幕与人物主讲字幕、信息卡与信息卡、强调大字与强调大字，不拿原片的片尾字卡对比新片的正文。尽量按原始画幅与相近的显示比例对照，分别看入场、中间态和完整停留：

| 项目 | 需要核对的实际特征 |
|---|---|
| 字形类别 | 黑体、宋体、手写、圆体、窄斜体；笔画端点、重心、轮廓与数字造型 |
| 层级 | 标题、正文、字幕、强调词、数字、注解各自的字体和字重，不能全部统一成粗黑体 |
| 字面与间距 | 字高、字宽比例、字距、行距、换行和对齐；同字号不等于相同可见字高 |
| 效果 | 描边颜色与厚度、阴影方向/偏移/模糊、发光、叠色；不要把每层文字都加粗描边 |
| 画面关系 | 文字与人物脸部、卡片边缘、字幕带和留白的关系；停留阶段要读得完 |

来源只标了字体名称但没有实际文件时，记录“原字体名称可见、文件/版本未知”。来源连字体名称也不能确认时，记录未知；不要凭相似外观宣称完全一致。

`TH-DY-19` 原参考出现“新青年体”名称。**公开配方默认使用可商用的OFL近似字体，当前为 Noto Sans SC 的近似方案**；也可基于参考重设计为 Douyin Sans，记录实际选择与差异。要用原字体，须由用户提供适合本次用途的授权字体。非商用版本不能作为开源包或商业默认字体。`TH-DY-21` 的原“江湖体”文件仍未知，Ma Shan Zheng 等OFL手写体只能标为近形替代。

## 官方OFL字体清单

[registry.json](../assets/fonts/registry.json) 保存8款字体的官方来源、下载快照SHA-256、字体文件SHA、真实字重/轴，以及OFL文件的独立SHA。字体二进制按项目下载，不新增到技能仓库。

| ID | 字体 | 真实字重 | 选用依据 |
|---|---|---|---|
| `sans` | [Noto Sans SC](https://github.com/notofonts/noto-cjk) | 可变100–900 | 简体正文、字幕、信息标签；按角色选择字重 |
| `serif` | [Noto Serif SC](https://github.com/notofonts/noto-cjk) | 可变200–900 | 宋体标题、数字或正文；不依赖系统宋体 |
| `douyin` | [Douyin Sans](https://github.com/bytedance/fonts/tree/main/DouyinSans) | 400 | 原生较粗的展示字；文件名Bold不代表应再请求800 |
| `smiley` | [Smiley Sans Oblique](https://github.com/atelier-anchor/smiley-sans/tree/v2.0.1) | 400 | 原生窄斜字形，适合经参考支持的标题/短句 |
| `kuaile` | [ZCOOL KuaiLe](https://github.com/google/fonts/tree/main/ofl/zcoolkuaile) | 400 | 不规则、活泼的展示字 |
| `huangyou` | [ZCOOL QingKe HuangYou](https://github.com/google/fonts/tree/main/ofl/zcoolqingkehuangyou) | 400 | 较规整的圆润展示字，与快乐体分别选用 |
| `longcang` | [Long Cang](https://github.com/google/fonts/tree/main/ofl/longcang) | 400 | 较松的手写标题与短句 |
| `mashanzheng` | [Ma Shan Zheng](https://github.com/google/fonts/tree/main/ofl/mashanzheng) | 400 | 毛笔手写强调字 |

这些字体各自保留OFL-1.1与版权信息，按OFL条件可用于商业项目，不改称本仓库MIT授权。随工程再分发时保留相应许可；改名、子集化或修改字体时另核对Reserved Font Name条款。系统字体“本机能用”不等于能打包开源。单字重字体始终使用其真实字重，不能通过请求800/900生成伪粗体。

下载助手仅用Python标准库，不向系统安装字体：

```bash
python3 <skill>/scripts/download_fonts.py --list
python3 <skill>/scripts/download_fonts.py --fonts sans serif douyin --dest ./project/assets/fonts
python3 <skill>/scripts/download_fonts.py --all --dest ./project/assets/fonts --verify-only
```

`--fonts` 按项目需要选择；`--all` 才处理全清单。助手下载字体及其独立许可、生成 `fonts.css` 和相对路径的 `font-manifest.json`，增量添加时保留此前仍通过校验的字体。Smiley同时验证官方release ZIP和选定WOFF2；其ZIP不含许可，助手从同版本官方仓库另取LICENSE。`--verify-only` 不联网、不写文件；只安装过部分字体时，用相同的 `--fonts` 范围核验。

本地文件或上游字节不符时停止，不能跳过SHA校验。确认要替换本地损坏文件时使用 `--replace-invalid`，它仍只接受清单中的精确字节。上游main链接可能更新；需要核对官方变更后版本化registry，不能随手把新哈希当作已验收。下载成功也不代表版式或完整成片已通过。

## 实现时保留的约束

- 按当前稳定风格ID与文字角色解析字体配置，至少区分标题、正文、字幕、强调/展示字、数字、注解。旧包装函数里的统一800不能覆盖手写体和正文角色；字幕单独配置字体、真实字重、字号、描边与行高。经实际参考验收后再冻结配置，不把尚在调试的全库参数写成标准答案。
- 测量前对每个实际CSS字体descriptor调用 `document.fonts.load`，确认返回非空且face已加载，再等待 `document.fonts.ready`。仅等待ready或只看CSS声明不能证明目标字体已加载。记录CSS alias、实际字体文件SHA、解析后的family与真实weight；字体内部名称含Thin但有合法可变轴时，检查轴与所用轮廓，不能仅凭名称判错。
- 以实际绘制字符核对相应字体的cmap，包含标点、数字和新文案中的少见字。字体覆盖旧片，不代表覆盖任意新稿。使用记录应包含family/weight、实际字符、原生帧索引和调用次数；warmup重复调用可计入但要说明。缺字或意外系统回退未解决时，不发布为已通过。
- 直接文字、缓存文字画布、字幕换行与高亮定位使用同一套测量和描画规则。字距与横向比例同时作用于测量和绘制；字距按实际字符/字素间隔计算。横向压窄保留字高，不拿整体缩字号替代。缓存画布要容纳字形外伸、描边和阴影偏移/模糊。
- 每次文字调用显式清理继承的阴影、字距和字体状态。零或负描边宽度真正禁止stroke，不能给Canvas设置0线宽后仍调用strokeText。
- 设定与角色、镜头相符的最小可读字号。达到下限仍溢出时，记录风格、帧、原文、字号、目标宽度与实际宽度；通过换行、调整卡片或改写等具体手段修复，不能把所有文字一起缩小。仅装饰文字可逐项注明越界理由，不对字幕或整个画面豁免。

## 最终验收

从**完整新编码MP4**抽取实际画面，与原片对应镜头核对上表；预检PNG和字体清单不能替代成片审片。覆盖受字体变化影响的开场、卡片、字幕、强调词以及运动中间态/完整停留，确认换行、描边、阴影、脸部安全与阅读时间。口播字幕按当前确认的单底部常规样式验收；来源的多处跟读文字不作为必须保留的风格特征。参考原本没有文字的镜头只检查应用设计，不把后来添加的文字称为原片复刻。

记录实际查看的输出SHA、帧与图片证据，区分“字体文件/字形覆盖通过”和“视觉近似程度”。字体、文案、布局或输出改变后重新检查相应实际成片，未解决的必读文字溢出、缺字或回退不发布。完整审片边界见 [quality-review.md](quality-review.md)。
