# 未经剪辑的自拍口播

输入是用户本人原视频时，默认走真人剪辑路线：保留原生声音和嘴部画面，无需 Fish、MiniMax 或数字人账号。直接交付本地 MP4。用户提供原片即授权本地可逆制作，保存原文件；缺少风格偏好时沿用已审核风格，不为每一步重新求批准。

最少提供原始 MP4/MOV 的绝对路径或文件。目标平台、目标时长、必须保留的句子、不能删除的停顿、参考片是可选信息；默认沿用此前确认的 9:16、1080×1920，不足分辨率要照实记录。原片横屏时先查看人物与安全区，不能机械中心裁切。

| 阶段 | 实际执行 | 产物/审核重点 |
|---|---|---|
| 收片 | ffprobe 检查尺寸、帧率、VFR、音轨、旋转，抽看头中尾；原片只读 | 素材记录、原片 hash |
| 听句与粗剪 | 转写原音；辨别重录、口误、重复句和有意义停顿；写保留区间与删除原因 | `edit-decision.json`，剪辑前后时间映射 |
| 形成母片 | 画面和声音用同一组保留区间裁切；切点按帧统一，对关键句首尾留自然余量 | 原声粗剪母片；实际检查切点、声音尾字和嘴部 |
| 定字幕 | 对粗剪后的最终音频转写/对齐，按自然短句复核 | 最终词轴、SRT；旧原片词轴不可直接沿用 |
| 编排 | 沿用已选固定口播配方，人物承担开头、关键结论、情绪转折和收尾；例子/关系/对比按句意插证据画面 | 镜头表、语义 shotbook；不机械按固定秒数切人物，艺术插镜按需启用 |
| 制作 | 按最终词轴编排动作，统一画风；原片主音不替换；画中画位置避开人脸和字幕 | 完整 MP4、逐个动画 MP4 |
| 审片 | 检查真实编码画面、连续切点、嘴型/原音同步、字幕与阅读负担；当前 Codex 审片并记录实际验证范围 | 完整稿＋每个动画的播放审核页＋绑定输出 hash 的报告 |

若用户只要精剪，不要把默认操作理解为强行删除所有空白/语气词。节奏服务于表达；自动静音检测只是候选位置。章节和句子是否可删由 Agent 根据语义作判断；不捏造新的表达。没有获准的真实证据时用清楚标明的解释示意，不冒充实拍事实。

## 可执行原声粗剪

编写 `edit-decision.json`，时间均为原片秒数；按时间顺序排列、不重叠。记录原因并留自然句界余量。空区间不是“原声不需要”的信号，直接拒绝。

```json
{"keep":[{"start":0,"end":8.2,"reason":"开场完整句"},{"start":12.1,"end":29.4,"reason":"保留第二次清楚表达"}]}
```

```sh
python3 <skill>/scripts/cut_master.py /absolute/raw.mp4 --edl /absolute/edit-decision.json --out /absolute/project/master.mp4
python3 <skill>/scripts/motion.py init /absolute/project/composition --video /absolute/project/master.mp4
```

`cut_master.py` 为保留区间统一量化帧界，画音同步 trim/concat，输出时间映射及指纹并全解码。VFR 输入默认转成检测到的平均帧率 CFR；若平均帧率异常或用户指定目标 FPS，显式 `--fps`。技术执行成功不等于语义粗剪已审核；必须看实际句首尾。脚本不做声线克隆、不购买 API、不直接去口水或自动重写口播。使用 MP4 输出，不覆盖原片或已存在成片。

首次真实自拍执行需验证该文件的原生同步、朝向、取景和内容；已有图库人物＋Fish 配音示意只验证构图和动效，不证明自拍实战或数字人口型效果。
