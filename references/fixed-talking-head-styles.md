# 固定口播风格：选择、锁定与套用

用户用编号或名称指定风格；网页展示实际视频，不接收选择、意见或评分。沿用项目已确认选择。缺少选择时在对话提醒一次，并继续收片、分析与字幕等独立工作。展示全部风格不需要先选择单款。

`assets/fixed-styles/catalog.json` 保存30个来源的稳定入口 `TH-DY-01` 至 `TH-DY-30`。同源包含不同编排时，保留命名子版本。共享语法明确关联；30个来源不等于30套独立新语法。花叔35艺术画风、8种通用动画语法仍分别管理，不能把编号跨库混用。

| 锁定项 | 可换内容 | 套用时实际检查 |
|---|---|---|
| RGB配色、渐变/阴影/描边 | 文案与强调词 | 编码后填色与半透明边缘分别对照；新文案不是原字形的像素复制 |
| 字体与文字层级 | 标题、问题、说明 | 原字体不明时使用配方声明的授权替代字体；检查当前文案的长短、换行和读字时间 |
| 归一化人物/证据窗口、圆角与层序 | 自拍原片、证据视频/图片 | 脸部占窗比例、上半身范围、手势、字幕安全区；不能让近景素材挤满圆窗 |
| 动作顺序、进入/退出、遮罩和混合方式 | 词轴上的触发词与停留时长 | 原片动作以原生帧记录；新口播按真实词轴迁移，缩放、滑入、裁切揭示分别执行 |
| 人物出镜/回归规则 | 原声粗剪母片 | 开头、关键论点、转折与结尾由人物承担；按表达安排，不机械每N秒插入 |

源参考固定字形、人物、美术、视频保留在私有调研工程。开源的配方是测量规则和版本身份，不携带原作者素材；套新文案需要授权字体和自己的素材。没有明确来源的证据不能变成事实画面。

当前公开版本为0.1.0：30个入口有基础机制配方，已完成的原生窗口另列验证范围；尚在精修的字体、颜色边缘、几何和子变体不作为完整逐帧验收。绑定版本表示采用该配方的明确范围，不表示所有效果或任意替换素材都通过。

## 可执行锁定

```bash
python3 <skill>/scripts/fixed_styles.py list
python3 <skill>/scripts/fixed_styles.py resolve TH-DY-13
python3 <skill>/scripts/fixed_styles.py bind /absolute/project --style TH-DY-13 --choice-source '用户在当前对话指定TH-DY-13'
```

先读取配方的 `readiness` 和 `validation`，不把已实测窗口推成整源完成或任意输入均通过。`bind` 把完整配方快照写入 `style-lock.json`，并写入 `brief.json.art_direction`。稳定ID、配方版本、原配方SHA和快照内容SHA共同绑定。保持无关 brief 字段；同一版本的已锁参数被修改时拒绝执行。新版本显式重新绑定，历史工程继续用历史快照。

用户说“第13款”时，按当前展示页上下文映射为稳定ID；上下文已明确就直接执行。独立CLI的裸数字会拒绝，避免与花叔第13款混淆。指定子版本时记录到镜头表；未指定子版本可按语义选择同一配方内的编排，不变更该风格的配色和文字体系。

## 编排和渲染

读取已锁配方，Agent 编写语义 shotbook 和项目 measured spec，使用可换槽位实际填入新素材。配方不会自动逆向任意视频或识别未知字体。人物需抠像时生成时间一致的动态 alpha；自带背景可直接用真实 A/V 母片。原生取景不足时先调整人物窗口，不能把演示素材的人体扩展当真实自拍像素。

在锁定项目中，`social` / `reference` / `reference-native` 的 spec 添加：

```json
{"fixed_style":{"id":"TH-DY-13","version":"0.1.0","recipe_sha256":"实际已锁配方SHA"}}
```

`produce.py` 检查配方与任务的身份；原片、所有图层素材、引擎、spec 参与 B-roll 缓存。brief 和 style-lock 同时参与制作指纹，改了配方必须重新编译/渲染。纯证据媒体和花叔艺术插镜仍要服从所选口播的构图与颜色体系，新增混合风格必须源于用户选择。

套用已学配方时，新 `reference` / `reference-native` spec 的 `reference` 绑定当前已接受的用户母片及对应原生窗口，而学习来源保留在配方的 provenance 中；图层使用本人帧、动态alpha、授权字体和新证据。无需重新下载教程才能渲染。根据当前母片FPS/PTS与真实词轴迁移动作，不能直接重放教程已剪成的帧。

新人物或新长短文案导致取景、换行或复杂动作存在实际不确定时，先核验相关代表镜头；已有配方能正常容纳素材时直接整片制作并审实际编码。研究样片只证明对应窗口与素材；替换字形、取景、嘴型与本人正式口播另记验证范围。

## 本机展示

`fixed_style_gallery.py --cases /absolute/cases.json --dir /absolute/review` 按稳定ID分组实际 MP4，展示名称、子版本、颜色、差异和逐帧对照入口，隐藏内部配方JSON。`precision_gallery.py` 生成同步对照；`serve_review.py` 仅本机服务。媒体SHA/原生窗口与渲染manifest不符时拒绝生成页面。选择和修改意见始终在对话中保存，由Agent关联实际版本。
