# 默认用当前 Codex 审片

本机默认流程是“本地工具检查 + 当前对话的 Codex 视觉/内容审查”。无需另外购买质检模型或填写 Gemini API key。`produce.py` 的机械成功只是交给 Agent 继续审片的阶段，不是等待用户另开一个服务。

1. 运行完整解码、尺寸/帧率/时长、帧数、音轨、A/V 时长和指纹检查。音频可测电平、波形与母片差异。
2. 当前 Codex 读取最终 MP4 抽出的真实画面。日常套用已有配方时覆盖首尾、关键切点、字幕换句和有风险的取景/新动作；新增风格或明确精细复刻时，密集检查每个效果的进入、停留、退出与衔接。阶段中心只能检查停留状态；有入场路径、逐字错峰或快速切换时，检查实际编码输出的原生连续进退场帧，包含前后衔接。联系表用于定位，不代替关键帧查看。
3. 按文案、分镜、素材和参考判断字幕内容、可读性、遮挡、人物裁切、证据对应、异常空白/冻结以及动画变化。静止停留不自动判为错误；动画多也不自动判为网感好。
4. 记录时间码、具体证据、影响、修法和未检查范围；修复后检查新输出。保留接受的A/V母片，默认三轮用于控制返工；必要修复或用户扩展范围记录理由后继续，不因轮数耗尽宣称完成。独立审片仅在适用规则明确要求或实际风险需要时增加，通常由当前 Agent 完成。
5. 写工程内 `codex-review.json` 或审片 Markdown，绑定 `output_sha256`，分别记录 mechanical、visual、transcript、audio 和 reference_fidelity 的 pass/fail/partial/unverified。只有实际核验过的项目才写通过；只抽看部分帧就说明采样范围。

当前工具链可以查看编码帧和分析本地音频，但不能把“抽帧/读转写”称为完整实时试听。没有实际听到声音时，发音、听感与自然度保持未验证；口型和快速转场不能仅凭稀疏帧断言精确同步。技术通过与成熟成片质量分开报告。修改输入或输出后，旧 QA 不能直接沿用。

## 从真实制作回流的检查

- 字幕先按原稿的自然短句复核句界，再使用实际词轴取首尾时间。自动字符数分组可能把“视频”等词拆到前后两屏；必须检查这种断词。不要均分整段音频制造词轴，也不要仅凭把识别字改成原稿就断言真实发音无误。
- 按最终词轴的实际阶段时长安排动画，包含错峰延迟、进入、完整停留和退出。最短阶段里的关键步骤词也应在切镜前完整出现，并留出可读的停留；不要把默认1.4秒等固定显现时长机械套到更短的语句。缩短动作或调整错峰，保持该风格的顺序、配色和动作特征。
- 逐字错峰入场时，尚未开始的元素（`q <= 0`）不绘制；最小缩放值不能让迟到字块提前残留。检查整条运动路径和相机变化后的实际位置，让字块避开脸部，尤其鼻部与正在说话的嘴部，不能只确认最终落点安全。
- 先等待 `document.fonts.ready` 再测量文字，避免中文字体加载前的尺寸导致裁切。
- 遮罩式标题入场必然暂时被遮挡。只有查看过该元素的密集转场采样，确认停留阶段完整可读后，才可对该标题标记 `data-layout-allow-overflow` / `data-layout-allow-occlusion` 并记录理由；不能对全画面或字幕关闭审计。若弹性曲线让标题超出遮罩，调整曲线或预留空间。
- 网上实拍片无原生音轨、未与新文案做口型驱动时，仅用作明确标注的 B-roll。不能把配上新声音的图库人物称为已经完成的口播数字人。

## 相机之后的主体安全区

按最终相机变换检查焦点圈、物内标签、波形与底片，不能只看世界坐标。焦点应落在实际人物/信息上，避免圈住空白衣服。字幕与固定说明带最后绘制；关键内容不能被它们盖住。仅装饰边缘出画可接受，须与波形、人物嘴部、要读的标签分别判断。原QA会把字幕自身报告为“进字幕带”，照实保留原报告并记录判断，不能全局关掉框景检查。

音频保留原定稿时，视频长度按帧向上量化再独立mux完整音轨，避免 `-shortest` 截掉尾字。分别记录容器音轨时长、原始样本数及AAC解码padding；波形/相关性不能验证真实听感。

## Gemini 是可选补充

Gemini 是 Google 的模型，在原方案中用作额外的视频理解评审。用户明确需要时，才使用 `scripts/review_gemini.py PROJECT --model MODEL --allow-remote`；它需要 `GEMINI_API_KEY`，会把实际视频代理和分镜发送给远程服务。账号/模型/费用需在真实环境验证，API 失败不能冒充质检通过。

默认静态视频采样可能漏掉快速动作，额外模型判断也不等于每一帧或口型都已检查。[Gemini 官方视频说明](https://ai.google.dev/gemini-api/docs/video-understanding)。

存在相机快推或复杂遮罩时，固定说明标签应在屏幕空间保持安全。检查动作中间状态和第一次快推末态：世界标签和相机可能先后移动，绘图函数也可能超出盒高。该风险窗口按真实输出密集复验；已有配方中的普通静止镜头不因此新增全片逐帧关卡。
