# Fish Audio MCP接入

适用：用户想先用现成官方音色和一张照片实测口播，而没有声音样本、API Key或已运行的数字人服务。可以把Fish MCP作为可选母片提供方；本地编辑与默认当前Codex质检照常。

核对日期2026-10-11。依据[官方MCP说明](https://docs.fish.audio/overview/mcp)、[数字人入口](https://fish.audio/ai-avatar-generator/)、[官方音色库](https://fish.audio/zh-CN/discovery/)。软件、套餐、模型需在实际使用时重查。

## 配置与身份

1. 先查本机Codex配置是否已有同一MCP，读取名字/地址/启用状态即可，不显示令牌或其他服务密钥。
2. 当前本机CLI帮助已验证的注册语法：`codex mcp add fish-audio --url https://api.fish.audio/mcp`。修改前把配置备份放在Codex配置目录，避免放进工程/压缩包。
3. Fish采用OAuth。登录必须由用户完成；使用 `codex mcp login fish-audio`，选择实际用于此次项目的团队。服务连接与客户端工具加载分别验证。
4. 本地已登记或CLI已完成授权都不证明当前对话已取得工具。只有实际可调用后才记录 `connected`。加载失败时保存状态并给出网页登录回调/连接重载步骤。
5. 不要求用户把密钥或OAuth令牌发到聊天。需要开发者API时另按适用声音skill处理环境密钥；MCP与API凭证不是一回事。

## 用现成音色而不是克隆

用户同意通用测试人物/声音时，可生成有明确标签的虚构人物，用Fish Official设计音色。记录音色页URL、voice ID、官方身份、语言、选择理由和许可/套餐依据，不把互联网声音当成用户本人声音。未听过样本时明确 `audition_status: not_listened`。

例：中文男声候选“梓轩Zixuan”，ID `5d29a99739c14d4ca3e4fe42193105b2`；备选Haoran，ID `d675c275d1d44e57b4ef3840c5a23209`。这只是有来源的候选，并未保证该模型/账号当前可调用，也未验证成片听感。

## 母片生成闭环

- 登录后查实际工具、模型、团队、额度和任务报价；网页列举的模型不等于该账号可用。
- 明确MCP消耗网页套餐credits，开发者API另行计费。免费API TTS不等于MCP视频免费。数字人视频套餐资格和实际报价以当次查询为准。
- 图像/视频按提供方报价确认步骤进行；用户已有明确预算及授权范围时复用，不重复问。没有已授权范围时，先完成照片、精确文案和具体短段方案，再请求对这笔报价的确认。
- 一位新人物/音色组合先做一段代表测试，检查发音、句尾、自然程度、口型、脸型、画幅与背景稳定性。优先使用已合格的独立音频驱动数字人，避免让后续视频再次随意改文案或声音。
- 注册/保存任务ID后才等待，重试先查历史；原始媒体下载到项目，失败按提供方状态处理。
- 母片若重建或改动音频，按native A/V成对保留，后续转写最终音频。不要覆盖旧配音造成口型错位。
- 接入下游 `motion.py init`、最终词轴、语义shotbook、HyperFrames渲染和当前Codex审片。阶段记录分开标注：配置、授权、工具可调用、配音通过、数字人通过、完整成片通过。

不强制用户同时接Fish、HeyGen API、MiniMax H3和远程质检。用已验证满足需求的提供方；有现成H3或用户另有指定时遵从既有路线。
