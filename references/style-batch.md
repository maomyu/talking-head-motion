# 多画风完整口播对照

用于用户要求所有画风各做一条完整口播。先沿用已接受的文稿、原声/配音、人物母片与字幕时间，再把每个指定画风应用到实际题材的道具、背景、材质和动作。数量与完整时长是交付要求；源房间三秒预览仅是配方参考。

画风选择遵循 [SKILL.md](../SKILL.md) 的“画风展示与对话选择”：网页只展示，用户在对话里告知；已指定不重问，未指定制作正式单版时展示后提醒。选画风优先复用既有画风库，不自动再次生成35条完整对照。网页编号按当前 `data.json` 的 `number` 解析为实际 `id`，两者不保证相同。

## 动画语法与艺术画风

8个参数化解说renderer决定信息的表达结构：白板、资料拼贴、动效文字、财经图表、数学可视化、产品界面、科普插画、叙事。第9张讲解员卡走完整场景和自有人物素材路线，未提供第9个 `--spec` renderer。35种艺术配方决定笔法、材质、造型、色板、光影与风格母题，两者属于不同维度。

组合时要把具体语义物件重建为所选画风。仅换解说模板的颜色不代表迁入该艺术场景；也不宣称现有8个renderer已自动实现280种组合。整片按内容选择事件动作、按镜头表锁画风，复杂组合用自定义scenes。

## 复用材料，重新写语义镜头

`assets/style-batch/catalog.json` 登记35个实际材料工厂及逐项限制，四个同目录JS提供接口与实现。载入顺序是完整引擎的 util/paint/kit/brush/render/motion/camera/diagram/collage/media，再载入 `shared.js`、`graphics.js`、`painterly.js`、`heritage.js`，再载入 `world_backplate.js`、`egypt_rim_coflow.js`、`shadow_card_occlusion.js`，最后项目的主题 scenes。埃及饰带补丁仅作用于02默认配方，其余画风直接使用原世界背景函数。画幅为1080×1920；其他画幅应重新构图，不能拉伸。

用 `window.KOUBO_STYLE_FACTORIES[id]()` 获取画风。具体接口见 [interface.md](../assets/style-batch/interface.md)。把新主题的物件交给 plate、pattern、line、clock；背景和母题也应服务主题。不要只换色板。真实人像保持实拍细节，不用代码造脸。35个画风共享语义事件是为了公平比较，用户选定后可进一步为该画风重写节奏与构图。像素版的关键中文必须用原尺寸文字层；参见 `pixel-readable-text.js`，在像素图层flush后按原相机变换写字。实片复查“看哪里”、流程节点、“剪辑”和“看懂什么”。

相机按真实时间计算，8-bit等道具可以步进。`world_backplate.js` 与同目录 `camera-integration.js` 给出沿已有CAM事件的相对视差接法；用单一离屏布景画布连续裁切，拒绝镜像、重复拼贴或羽化接缝。原装饰母题可能被裁切；埃及/哥特/新艺术另绘真实矢量页边。远景横移160px、纵移70px，缩放锚点位于上部以保留主体；覆盖范围按当前轨迹计算，新轨迹超出最小倍率或带旋转会失败，需重新计算覆盖。当前是单背景的兼容分层，不是每种原作的完整多层场景。实际艺术背景占比很大时，固定屏幕背景而只移动前景会让快动作弱化，应先检查世界相机关系，不能加无因闪屏或降门禁。

埃及配方的四色实体饰带应随已有相机作近景相对平移/倍率变化；用 `egypt_rim_coflow.js` 关闭其固定视口回填并绘制真实饰带层。长横移时饰带可以自然离画，底层连续布景保持覆盖。固定高反差饰带曾使实际整片快速动作门禁变红；近场修正版按未修改的原规则已验证。仍须按当前题材重新看文字、人脸与边框出入，不把旧配方的验证外推给新镜头。

层次固定为：背景→装饰母题→语义道具/真实照片/标签→温和光照→字幕。装饰画在前景曾遮住“看哪里”“数字人”“看懂什么”；审片需复查这些密集信息段。不要把装饰从信息层移开后，只检查第一帧。共享压力镜头的前景大卷盘也曾遮“字幕”首字；纸卡要在卷盘之后绘制或留出明确间距，并检视该镜头首中尾。

当前工厂是主题材料实现，不代表逐像素复制艺术原作。已披露例外包括罗马规则镶嵌格而非Voronoi切片、马蒂斯缓存颜料与切边而非逐像素roughen；以各工厂metadata为准。`metadata`中的机制必须随代码变化更新。

## 同一母片与完整时间轴

- 自拍素材依 [raw-talking-head.md](raw-talking-head.md) 保留原画面与原声共同剪切；不复制循环图库段，不生成替代配音。口型时轴绑定实际最终母片。
- 每版在相同的开场、重点、情绪转折、结论和收尾回到人物。先审核主画面裁切及回归频次，再铺艺术材料。
- 所有版使用同一已确认完整音轨。短预览要显式标记；完整稿禁止以 `-shortest` 截尾。字幕保持相同时间与高对比，画风不能牺牲可读性。

项目页面须暴露 `__canvas`、`__total`、`__style`、`__ready`/`__bootFailed`、异步 `prepare(t)` 与确定性 `renderFrame(t)`。时长来自当前口播，不把示例75秒写成通用长度。项目自行准备本地人物帧、音轨、字幕、字形和主题场景；缺材料时失败。

```sh
python3 <skill>/scripts/style_batch.py --project <项目> --audio <已接受完整音轨> --ids 09_postimp --stills --out <项目>/预检
python3 <skill>/scripts/style_batch.py --project <项目> --audio <已接受完整音轨> --jobs 3 --out <项目>/完整画风对照
```

不传 `--ids` 渲染35版；指定ID可制作单版或候选组。默认使用项目的 `engine/`，局部修复保留另一冻结来源时可用 `--engine <该来源的目录>` 明确选择；该目录必须包含页面和所需素材。脚本提供本地H264导出和一次AAC编码、记录帧数与源指纹，未负责文案理解或独立审片。`--resume`仅复用音轨、源码、视频指纹匹配的同类完整稿/显式预览。用户之后只要一条视频时，不自动再渲35版。

透光画风的文字纸卡必须遮住下层，交换绘制顺序不能解决multiply混色。`shadow_card_occlusion.js` 对当前V4 `notes()` 的seed43文字区先以source-over铺不透明浅皮纸，再叠原镂孔皮片；底纸继承调用方globalAlpha，不能强制为1。新题材必须显式识别语义卡、核对文字区域及进场状态；该补丁不识别任意文字卡。实际MP4重点看压力镜头“字幕”首字和错字示意卡，原尺寸源帧通过后仍需重新编码审片。

## 验证与审核页

每版记录实际MP4 SHA、音轨来源SHA、编码帧数、宽高、帧率、时长、完整解码、母片声音一致性及画风机制。先按各版真实色板跑镜头表lint，再做逐镜Canvas确定性与运动筛查、实际MP4的原film gate、原deliver事实区。用户明确要求的蓝紫配方可按原gate的 `--allow-blue-purple` 写出理由；不改指标阈值。

单一画风局部修复时，归档旧源码/视频/审片指纹，按最终每条实际源码快照记录版本；未改的成片保留原版本。批次可以明确包含多个冻结源版本，不能把其他旧视频追认成新源码导出的结果。

机械检查不等于风格通过。长片至少两位未参与制作的Agent独立审片：用实际编码帧检查每镜早/晚、标签/人脸/字幕，剪片与修正等关键连续窗按原帧率密集检查。报告写明看过的范围、连续窗口及音频实际检查方式，绑定新版SHA；修复后重审新版。低频抽帧不能声称全片逐帧或完整实时试听。

审核页提供所有完整视频的播放/下载、35项机制说明、镜头跳转与可选双版同时间对照。默认不提供用户填写意见、打分、审核状态、记时间、保存或导出记录的入口，也不依赖浏览器localStorage维护审核数据。用户通过对话说明选定画风、修改要求和确认；由 Agent 在项目中关联实际MP4 SHA记录，指向新版时重新核对。机器检查或Agent评价不代替用户确认。源房间预览另作配方参考。音频、实拍人物、供应商配置与这些成片留在工程，不随技能包发布。

已有35项实际验证manifest时，用 `scripts/style_review.py --manifest <验证清单.json> --storyboard <storyboard.json> --captions <字幕.srt> --presenter-note <当前人物的真实状态> --out <审核页面>` 建立页面；再用 `scripts/serve_review.py --dir <审核页面> --port <本机端口>` 打开。manifest每项必须包含真实path/poster/video_sha256/duration/frames/fps/width/height/metadata、full_av_decode、audio_packet_identical、accepted_aac_packet_sha256及原gate结果。构建器核对媒体指纹、母片一致、完整时长和无红灯；独立审片报告另外保存在项目，构建器不推断艺术质量通过。
