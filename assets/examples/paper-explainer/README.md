# 纸本口播完整场景：已制作的代码例子

这是按实际75秒口播新写的物体场景例子，供后续Agent学习复杂scene的构图、纸张材料、底片贯穿、关键词动作和字幕安全空间。`scene-example.js`不是自动填字模板；`story-example.json`是对应的镜头结构。示例不携带配音、人物图片/视频、用户数据或字体文件。

它展示手机吐底片、熬夜剪辑台、字幕擦改/照片翻找/动效尺、按句界剪片、实物叠放、累计四步白板、结论回人物、真实音轨波形检查和合卷收尾。调用原库 CAM/CL/MD/DG/MO；用项目最终词轴重写动作发生时刻。

使用前：

1. 通过 `huashu_full.py init` 建新工程，读 `references/huashu-full-production.md`；按新文案写镜头表并lint。
2. 选用示例的具体物体函数，按新句意重写事件、屏上字、位置和相机，避免照搬所有道具与旧构图。准备覆盖实际中文字的项目字体。
3. 绑定工程自己的 `window.FILM`、字幕、真实音轨 `VOICE_ENVELOPE`、本地图片帧和canvas。缺素材应失败，不能退成空白。
4. **自拍原片须按最终母片的全局时刻取原视频帧，配同一原生声音。** 例子中12.12秒图库视频的循环/source_start，只适用于明确标注未对口型的旧构图示意，不能用于自拍真人或数字人最终母片；应删除循环并按真实FPS、帧数、方向和裁切重新接入。人物未对口型标签也只适用于该图库例子，真实母片验证同步后使用合适的项目说明。
5. 每次修改相机后重新检查主体、物内标签、波形与字幕安全空间。最终逐镜QA、实际编码帧及独立审片完成后，才可称当前输出通过。

源库未承诺任意视频自动逆向复刻。这个例子展示的是可审阅、可修改的场景重建代码，不保证新题材只换文案即可完成。
